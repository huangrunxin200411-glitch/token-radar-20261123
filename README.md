A token launch radar: 198 pre-token protocols ranked by implied value, each with a seven-step farm plan, on a sortable, filterable dashboard. The value model reads its multiple off the market itself — each category's median market-cap / TVL ratio among live-token protocols — and sets aside wrapped, staked and bridged products, whose token already trades.
